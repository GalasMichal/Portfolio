# Michal Galas Portfolio

Angular 21 Portfolio — Webentwicklung, GIS, KI-Workflows.

## Development

```bash
npm install
npm start
```

Open `http://localhost:4200/`.

## Build

```bash
npm run build
```

Output: `dist/portfolio/browser/`
